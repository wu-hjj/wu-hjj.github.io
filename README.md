# Hongjin Wu — academic website

Website: https://wu-hjj.github.io/

A responsive academic homepage built with plain HTML, CSS, and a small progressive-enhancement script. No build step, package installation, or paid hosting service is required.

## Updating the site

- Edit `index.html` to update the biography, publications, talks, links, and experience.
- Edit `styles.css` to change the appearance.
- Replace `assets/portrait.png` to update the portrait.
- `script.js` highlights the current navigation section; the content works without JavaScript.
- Update the date in `sitemap.xml` when substantially changing the content.

GitHub Pages publishes the `main` branch from the repository root. Changes committed to `main` are published automatically. `.nojekyll` tells GitHub to serve the static files directly.

## Content

The site was prepared from Hongjin Wu’s public academic homepage and original publication records. Publication links point to arXiv or publisher DOI records; CV and presentation links retain their public Google Drive destinations.

The author’s text and portrait remain their respective owner’s content. No analytics, external fonts, or tracking scripts are included.
