# Hongjin Wu — academic website

Website: https://wu-hjj.github.io/

A responsive, single-column academic homepage built with plain HTML and CSS. The page uses a white background, black text, and a portrait at the top right. No build step, package installation, or paid hosting service is required.

## Updating the site

- Edit `index.html` to update the biography, publications, talks, links, and experience.
- Edit `styles.css` to change the appearance.
- Replace `assets/portrait.jpg` to update the portrait.
- Edit `gallery.html` to update the Gallery of Global Synchronizing Graphs page.
- Update the date in `sitemap.xml` when substantially changing the content.

GitHub Pages publishes the `main` branch from the repository root. Changes committed to `main` are published automatically. `.nojekyll` tells GitHub to serve the static files directly.

## Content

The biography, research description, presentations, experience, and closing quotation follow Hongjin Wu’s Owlstown editor as reviewed on 28 October 2026. Publication titles and years follow that page, with the author’s preferred publication-entry format retained. The two expandable research summaries reproduce the abstracts on arXiv:2512.21935v3 and arXiv:2511.12646v6; their formulas use native MathML. The gallery retains its original “Coming soon” content. There is no custom site icon.

The author’s text and portrait remain their respective owner’s content. No analytics, external fonts, or tracking scripts are included.
