# Academic website

Website: https://wu-hjj.github.io/

A minimal academic website built with plain HTML and CSS, featuring a single-column layout, a pure white background, blue links, publications, presentations, and experience.

## Updating the site

- Edit `index.html` to update the content and links.
- Edit `styles.css` to change the appearance.
- Replace `assets/portrait.jpg` to update the portrait.
- Update `sitemap.xml` when substantially changing the content.

GitHub Pages publishes `main` from the repository root. No build step or package installation is required. `.nojekyll` serves the static files directly.

## Content

The page retains the supplied academic content. Research summaries use the original abstracts in compact, single-paragraph form. No custom site icon, analytics, external fonts, or tracking scripts are included.
