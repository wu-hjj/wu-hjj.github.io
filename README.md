# Academic website

Website: https://wu-hjj.github.io/

A minimal academic website built with plain HTML and CSS, featuring a single-column layout, a white background, publications, presentations, and experience.

## Updating the site

- Edit `index.html` to update the content and links.
- Edit `styles.css` to change the appearance.
- Replace `assets/portrait.jpg` to update the portrait.
- Paper images are stored in `assets/papers/`; provenance is recorded in `assets/papers/sources.json`.
- Update `sitemap.xml` when substantially changing the content.

GitHub Pages publishes `main` from the repository root. No build step or package installation is required. `.nojekyll` serves the static files directly.

## Content and images

The page retains the supplied academic content. Research summaries use the original abstracts in compact, single-paragraph form. Images include original paper figures and explicitly labeled schematic illustrations. Source links and credits are provided alongside the figures. No custom site icon, analytics, external fonts, or tracking scripts are included.
